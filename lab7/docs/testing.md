# Отчёт о тестировании REST API

| № | Запрос | Ожидаемый код | Полученный код | Комментарий |
| :- | :--- | :-: | :-: | :--- |
| 1 | `GET /api/repairs` | 200 | 200 | Успешное получение списка заявок |
| 2 | `GET /api/repairs/1` | 200 | 200 | Успешное получение объекта по ID |
| 3 | `POST /api/repairs` | 201 | 201 | Заявка создана, есть заголовок `Location` |
| 4 | `POST /api/repairs` (короткое имя) | 422 | 422 | Ошибка валидации (`title` < 3 символов) |
| 5 | `POST /api/repairs` (некорректный JSON) | 400 | 400 | Ошибка формата JSON |
| 6 | `GET /api/repairs/999` | 404 | 404 | Заявка с таким ID не существует |
| 7 | `DELETE /api/clients` | 405 | 405 | Метод DELETE не разрешён для `/api/clients` (есть `Allow`) |
| 8 | `DELETE /api/clients/1` | 409 | 409 | Конфликт при удалении клиента с заявками |
| 9 | `DELETE /api/repairs/1` | 204 | 204 | Заявка успешно удалена, тело ответа отсутствует |
