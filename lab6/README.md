## Цель работы

Изучить основы разработки серверной части веб-приложений на PHP, создать структуру проекта, реализовать маршрутизацию HTTP-запросов и разработать контроллеры для обработки запросов пользователей на основе архитектурного паттерна MVC.

---

## 2. Назначение каталогов проекта

* `public/` — единственная директория, доступная из веб; содержит единую точку входа (`index.php`) и статические файлы стилей.
* `app/Core/` — ядро системы (класс маршрутизатора `Router.php`).
* `app/Controllers/` — контроллеры для обработки HTTP-запросов (`HomeController.php`, `RepairController.php`, `ClientController.php`).
* `app/Models/` — модели для работы с хранилищем JSON (`RepairRepository.php`, `ClientRepository.php`).
* `app/Views/` — шаблоны представления страниц.
* `routes/` — конфигурация маршрутов приложения (`web.php`).
* `config/` — глобальные настройки приложения (`app.php`).
* `storage/` — хранилище данных в формате JSON (`repairs.json`, `clients.json`).

---

## 3. Таблица маршрутов (Routes)

| Метод | URL-адрес | Контроллер и метод | Назначение |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | `HomeController::index` | Главная страница со статистикой |
| `GET` | `/repairs` | `RepairController::index` | Список всех заявок с фильтрацией |
| `GET` | `/repairs/create` | `RepairController::create` | Форма создания новой заявки |
| `GET` | `/repairs/{id}` | `RepairController::show` | Просмотр отдельной заявки |
| `POST`| `/repairs` | `RepairController::store` | Сохранение новой заявки |
| `GET` | `/clients` | `ClientController::index` | Список клиентов |
| `GET` | `/clients/{id}` | `ClientController::show` | Просмотр клиента и его заявок |
