# Лабораторная работа №5

## Реализация клиентской логики

**Курс:** Архитектура современных информационных систем  
**Студент:** Прилепская Ева (гр. ИТД-31)  
**Предметная область:** Система управления заявками на ремонт

---

## Цель работы

Изучить основы разработки клиентской части веб-приложений, реализовать обработку пользовательских событий, взаимодействие с сервером посредством асинхронных запросов и динамическое изменение содержимого веб-страницы с использованием JavaScript.

---

## 1. Структура проекта

Код клиентской части размещен в директории `lab5/src/`:
* `index.html` — HTML-разметка пользовательского интерфейса.
* `css/styles.css` — стили оформления страницы.
* `js/mock-data.js` — учебные данные (заявки на ремонт) и макет API-маршрутов.
* `js/mock-api.js` — эмулятор работы сервера (обработка `fetch`).
* `js/app.js` — клиентская логика (обработка событий, DOM-манипуляции, асинхронные запросы).

---

## 2. Реализованный функционал

1. **Обработка событий (Events):**
   * Перехвачена отправка формы (`submit`) с помощью `event.preventDefault()`.
   * Добавлена валидация формы (проверка минимальной длины темы заявки).
   * Подключены обработчики событий `click`, `change` и `input` для интерактивных элементов.

2. **Динамическое изменение DOM:**
   * Реализована генерация строк таблицы заявок на основе данных с сервера (`document.createElement`).
   * Добавлена возможность изменения статуса заявки («Выполнено» / «В работу») с обновлением интерфейса.
   * Реализовано удаление заявок из таблицы с подтверждением действия и перерасчетом счетчика.

3. **Асинхронные запросы (Async / Await / Fetch):**
   * Реализована функция `loadTasks()` для выполнения асинхронного `GET`-запроса к `mock API`.
   * Добавлена фильтрация и поиск заявок без перезагрузки страницы.
   * Обработаны состояния интерфейса: Загрузка, Отображение данных, Пустой результат, Ошибка.

## Вывод

В ходе лабораторной работы были освоены базовые принципы разработки клиентской логики на JavaScript. Реализовано полноценное интерактивное веб-приложение, поддерживающее асинхронную работу с данными без перезагрузки страницы.
