Вариант 16: Система управления заявками на ремонт

Анализ предметной области:
Система предназначена для обработки заявок на ремонт помещений или оборудования. Пользователь должен иметь возможность сообщить о неисправности и указать ее описание. Сотрудники технической службы должны получать заявки, назначать ответственных и изменять статус выполнения.

Пользователи системы:

1. Пользователь — создает заявку, указывает неисправность.
2. Сотрудник технической службы — принимает заявку, назначает ответственного, меняет статус.

Функциональные требования:

· Создание заявки на ремонт.
· Указание описания неисправности.
· Назначение ответственного сотрудника.
· Отслеживание статуса выполнения заявки.
